# Orthodox Clipper — Windows App (.exe)

Windows desktop wrapper for [Orthodox Clipper](https://orthodoxclipper.pages.dev), built automatically in the cloud with GitHub Actions.

## How to get the .exe

1. Open the **Actions** tab in this repository on GitHub.
2. Click the latest **Build Windows EXE** workflow run.
3. Scroll down to **Artifacts** and download **`orthodoxclipper-exe`**.
4. Unzip it and double-click **`Orthodox-Clipper-Windows.exe`** to run.
